# Project Resources

**Project:** RP-Cloud Labs Tool-Session Service  
**Contributor:** Igiraneza Jean Wilson  
**Registration Number:** 26RP00329

## 1. Introduction

Project resources are the people, equipment, software, and infrastructure required to develop, test, deploy, and maintain a software system.

This document identifies the resources needed for the RP-Cloud Labs Tool-Session Service.

## 2. Human Resources

Human resources are the people involved in developing and managing the project.

| Role | Responsibility |
|---|---|
| Project coordinator | Organizes activities and monitors progress. |
| Backend developer | Develops APIs and server-side functions. |
| Frontend developer | Develops user interfaces. |
| Database developer | Designs and manages database structures. |
| DevOps engineer | Manages Docker, CI, and deployment activities. |
| Tester | Tests system functions and reports errors. |
| Documentation contributor | Prepares and updates project documentation. |

The six group members share responsibilities according to their assigned activities.

## 3. Hardware Resources

The following hardware resources are required:

| Resource | Purpose |
|---|---|
| Laptop or desktop computer | Writing and testing application code. |
| Internet connection | Accessing GitHub and other online resources. |
| Router or network connection | Connecting computers and services. |
| External storage or backup | Keeping copies of important project files. |

## 4. Software Resources

The project uses the following software tools:

| Software | Purpose |
|---|---|
| Visual Studio Code | Writing and editing source code. |
| Node.js | Running the backend application. |
| Express.js | Building REST API endpoints. |
| PostgreSQL | Storing application data. |
| Redis | Supporting caching and other temporary data operations. |
| Apache Kafka | Supporting event messaging where configured. |
| Docker | Packaging applications into containers. |
| Docker Compose | Running multiple services together. |
| Flyway | Managing database migrations. |
| Git | Tracking code changes. |
| GitHub | Hosting the repository and managing Pull Requests. |
| GitHub Actions | Automating CI checks. |
| Postman or curl | Testing API endpoints. |

## 5. Infrastructure Resources

Infrastructure resources support the execution and communication of system components.

The project requires:

- A development environment for writing and testing code.
- Docker containers for running application services.
- A PostgreSQL database environment.
- Network connectivity between services.
- A GitHub repository for source-code management.
- A deployment environment for future hosting.

## 6. Development Environment

The project development environment includes:

- Operating system: Windows with WSL Ubuntu support.
- Backend: Node.js and Express.js.
- Database: PostgreSQL.
- Containerization: Docker and Docker Compose.
- Version control: Git and GitHub.

These tools help developers build and test the system consistently.

## 7. Estimated Resource Costs

The project uses existing student computers and free or open-source development tools wherever possible.

| Resource | Estimated Cost |

## 8. Resource Management

The team will manage resources through the following practices:

1. Assign tasks according to group members' responsibilities.
2. Use GitHub to organize source code and documentation.
3. Use Docker Compose to manage development services.
4. Keep project files organized.
5. Back up important project information.
6. Use available open-source tools to reduce costs.
7. Monitor resource usage during development and testing.

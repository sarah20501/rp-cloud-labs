# Skills-Gap Assessment
## RP-Cloud Labs Tool-Session Service

### 1. Introduction

The RP-Cloud Labs project aims to develop a platform that allows students to request access to hosted learning tools such as Visual Studio Code and other practical learning applications.

Developing and maintaining this system requires technical knowledge and teamwork. This assessment identifies the skills required for the project, the skills that group members currently possess, and the areas where additional learning or training may be necessary.

### 2. Objectives

The objectives of this assessment are to:

- Identify the technical and professional skills required for the project.
- Assess the current skills of the six group members.
- Identify missing skills and areas that need improvement.
- Recommend learning activities to improve the group's capabilities.
- Support successful development, testing, and maintenance of the system.

### 8. Assessment Method

The following methods will be used to collect information about the group's current skills:

1. Ask each group member to complete a skills self-assessment.
2. Discuss each member's previous experience and practical knowledge.
3. Give practical exercises where necessary.
4. Compare the collected skill levels with the project requirements.
5. Identify the skills that need improvement.
6. Recommend suitable training and learning activities.

### 9. Conclusion

The skills-gap assessment helps the RP-Cloud Labs team understand the knowledge and abilities required to complete the project successfully.

By assessing the current skills of all six group members, the team can identify areas that need improvement and plan appropriate learning activities.

The assessment should be reviewed throughout the project to ensure that the team continues developing the skills needed for successful implementation and maintenance of the Tool-Session Service.
